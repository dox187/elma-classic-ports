# CG Pixel 3x5 Mono

CG Pixel 3x5 Mono by Ilmari Karonen (vyznev), 2017.
The font is released under the [CC0 1.0 Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).

- [Author's font page](https://fontstruct.com/fontstructions/show/1404346)
- [Author's license statement](https://fontstruct.com/fontstructions/download/1404346)
- [BDF distribution](https://github.com/tidbyt/pixlet/blob/main/fonts/CG-pixel-3x5-mono.bdf)

The GBC UI uses the original bitmap at one pixel per font pixel, with a
four-pixel character advance. Two characters share each eight-pixel tile.
